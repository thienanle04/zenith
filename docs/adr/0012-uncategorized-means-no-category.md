# Uncategorized means no category

The owner only sees and chooses categories they created. Modify-balance and fee are system categories: they are never shown and cannot be renamed. An income or an expense with no category is uncategorized. There is no uncategorized category to rename or delete. Changing an income, an expense, or a transfer into one of the other two clears its category so the owner chooses again.

A visible "Uncategorized" category would be a row the owner would try to edit, which is the thing this avoids.
