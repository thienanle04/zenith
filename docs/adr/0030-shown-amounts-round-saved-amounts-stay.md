# Shown amounts round, and saved amounts stay exact

A currency's transaction amount decimal precision is how many digits a transaction amount in that currency is typed, shown, and saved with. It is a whole number from 0 through 4. VND, JPY, and KRW start at none, and every other currency starts at two, which is the usual minor unit. The owner can change one currency on its own. Changing it does not rewrite amounts already saved, so raising the precision later shows the stored digits again.

What is shown rounds half away from zero to the current precision. Each figure rounds on its own, so two stored expenses of 0.40 can show as 0 and 0 while their balance shows 1. A total sums the stored amounts, and only the finished total rounds. Net worth converts through the rate list first. A period total converts through each transaction's stored exchange rate first. Opening a transaction shows the rounded amount, saving stores that rounding, and leaving without saving keeps what was stored. Saving a balance that already matches the stored balance at the current precision creates no balance adjustment. Typing a different balance stores the exact signed difference, including digits beyond the current precision: a stored 10.25 changed to 11 stores 0.75, and the list shows 1. When an account changes currency, the suggested balance is rounded to the new currency's precision, and the owner can still change it before saving.

The alternative was to rewrite every saved amount when the precision changed, so the screen and the books would always show the same digits. The old digits would then be gone.
